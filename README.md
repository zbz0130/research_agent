# 许愿机 / WishForge

> 面向科研人员的证据驱动研究工作台：把模糊的概念或研究想法，整理为可追溯、可理解、可继续验证的研究线索。

## 产品能力

### 概念分析

在工作台输入一个概念，例如 `Attention Mechanism`、`LoRA` 或 `KV Cache`，即可按研究阶段选择分析方式：

- **快速解释**：直接生成面向不同受众的易懂说明，帮助快速建立直觉；
- **文献解释**：检索公开论文元数据，整理论文、摘要级证据卡、概念关系与技术演变；
- **研究线索**：在文献解释基础上扩展检索，结合方法对比、限制与 future work，生成待验证的研究方向和最小验证步骤。

论文检索可合并 arXiv、OpenAlex 与 Crossref 的公开资料；单个来源不可用时，其余来源仍可继续提供结果。

### 证据卡与主张—证据账本

系统将解释中的定义、机制、演变与限制拆成原子主张，并关联到可见的论文摘要或公开章节证据。每条主张都会显示证据关联、覆盖情况、置信度和后续人工核验建议，便于区分“已有资料线索”和“已经人工确认”。

### 研究 Brief 与社区线索

研究模式会汇总三类互相区分的线索：

- 社区讨论中的问题与需求；
- 模型或规则生成的探索性脑暴；
- 论文摘要中的限制与 future work 线索。

系统将学术证据、社区信号和模型候选分栏呈现，并保留每条候选的来源、风险、可行性和建议的最小验证路径。默认可读取公开 Hacker News；X 与 Reddit 可在配置官方凭据后启用。

### 可交互概念图

每次文献或研究分析都可以生成概念关系图。图中使用真实节点与连线呈现概念、问题、方法、研究方向和证据关系，并支持：

- 缩放、平移、拖拽、搜索和节点详情查看；
- 新增或编辑节点、关系和图谱名称；
- 保存图谱与手动布局，之后可随时回看；
- 并排查看多张图，或按节点生成临时局部视图；
- 选择多张图进行比较，发现可跨领域借鉴的机制与验证思路。

自然语言图谱修改会先被转换为有限的 `GraphPatch` 提案。提案会显示具体操作与警告，只有人工批准后才会应用；用户的手动编辑则立即保存。版本检查会防止旧提案覆盖新的图谱修改。

### 研究方向图（Overview）

完成文献或研究分析后，可生成“主题 → 研究方向 → 细分方向 → 论文证据”的交互式研究方向图。每个方向会保存专属检索范围、论文和组织过程；可以点击节点查看问题、方法、年份、来源与可用证据，并可继续展开某个方向或重新处理失败方向。

开放获取的 arXiv 论文会尽可能提取 Introduction、Method、Experiment、Discussion、Conclusion 等公开可读取章节；无法读取时会明确回退到摘要范围。

### 创新与查重

在“创新与查重”页面输入研究想法后，系统会输出：

- 本次实际使用的检索词和检索范围；
- 匹配论文及其摘要级证据；
- L0–L4 相似度分级与相似理由；
- 可能差异、替代方向和最小验证步骤；
- 人工审阅状态、审阅人和备注。

研究分析、研究方向图和跨图比较也可产生探索性的创新候选，并完整保留其来源、相近工作、风险提示和验证建议。

### 实验方案草案

用户可以从自由文本、创新候选或查重结果生成结构化实验方案，包括：

- 研究假设与基线；
- 自变量、控制变量和评价指标；
- 消融设计、预期结果与失败判据；
- 资源估计与关联证据；
- 人工批准、退回或拒绝状态。

当前版本只生成可审阅的实验计划，不会执行代码、训练模型或发起真实实验。

### 项目、历史与桌面使用体验

分析任务、项目、概念图、研究方向图、GraphPatch、查重记录和实验方案均保存到本地 SQLite，可在重启后继续查看。Windows 桌面版首次打开会引导配置服务；论文检索、社区检索、解释模型和实验执行使用彼此独立的配置与凭据槽位，页面仅显示脱敏状态。

## 使用流程

```text
概念 / 研究想法
        ↓
论文与社区线索检索
        ↓
证据卡、易懂解释与概念图
        ↓
研究方向、查重与创新候选
        ↓
人工核验后的实验方案草案
```

## 结果边界

- 论文证据主要来自公开元数据、摘要和可读取的开放章节；使用结果前仍应人工阅读原文核对。
- 创新候选与研究空白是当前检索范围内的待验证假设，不是原创性证明。
- L4 仅表示在本次记录的数据库、关键词、论文数量和公开资料范围内，未发现直接等价工作；不表示全球范围内不存在相同研究。
- Demo 资料、规则回退与模型生成内容均会保留相应标识，不应当作正式论文结论。
